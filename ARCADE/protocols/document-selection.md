# Protocol: Document Selection

Agents should let the project define its documents. Do not force every game into the same document set.

## Steps

1. Classify scale:
   - Project
   - System
   - Feature
   - Task
   - Bug
   - Research

2. Classify domains:
   - Concept
   - Product
   - Design
   - Technical
   - Art
   - UX
   - Content
   - Audio
   - Narrative
   - Levels
   - Production
   - Validation
   - Release
   - LiveOps

3. Identify genre implications:
   - Cards
   - Puzzle
   - Shooter
   - RTS
   - RPG
   - Simulation
   - Strategy
   - Platformer
   - Multiplayer
   - LiveOps
   - Procedural
   - Narrative-heavy

4. Decide current documents needed.

5. Update the relevant folder README with new, renamed, obsolete, or re-scoped documents.

## Rule

No document without:

- a reader
- an owner
- a decision or workflow it supports
