# Protocol: Asset Manifest

The production plan should track asset needs explicitly.

## Asset status values

- Missing
- Reference only
- Placeholder
- In progress
- Ready for integration
- Integrated
- Needs revision
- Approved
- Deprecated

## Asset manifest columns

- Asset
- Type
- Status
- Owner
- Needed for
- Source or location
- Integration notes
- Validation notes

## Rule

A slice should identify minimum asset needs, including placeholders, so the playable experience can be validated.
