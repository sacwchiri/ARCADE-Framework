# Protocol: Definition of Done

Different work has different definitions of done.

## Gameplay feature done

- Rules documented
- Code implemented
- UI communicates state
- Feedback exists, even placeholder
- Validation checklist passes
- Human has played it
- Known issues are ticketed
- Documentation updated if behavior changed

## Art asset done

- Meets art direction
- Meets technical art constraints
- Imported correctly
- Integrated in context
- Validated at target camera/resolution/platform
- Human or Art Director approved

## Slice done

- Player-visible result works end-to-end
- Required experience layers exist
- Integration report exists
- Validation report exists
- Human playtest completed
- Tickets created for known issues
- Human accepts the slice or sends it back for iteration
