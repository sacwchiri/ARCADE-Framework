# Protocol: Conflict Resolution

Agents will disagree. This protocol defines how conflicts are resolved.

## Common conflicts

- Systems Designer wants a mechanic that Technical Architect says is risky.
- Art Director wants fidelity that Technical Art says exceeds budget.
- UX Designer wants clarity that Director says reduces mystery.
- Production Planner wants smaller slices than Director wants.
- Validation finds confusion in a mechanic the team considers core.

## Resolution rules

- Product direction conflicts go to Director + Human.
- Technical feasibility conflicts go to Technical Architect + Human when cost/scope is significant.
- Art fidelity/performance conflicts go to Art Director + Technical Art + Human.
- UX clarity/fantasy conflicts go to UX Designer + Director + Human.
- Production scope conflicts go to Production Planner + Director + Human.
- Acceptance conflicts go to Validation + Human.

## Output

Document the conflict, options, tradeoffs, recommended path, and human decision.
