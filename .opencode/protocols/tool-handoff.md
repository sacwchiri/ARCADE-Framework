# Protocol: Tool Handoff

Tool calls must return a compact handoff that makes the next action obvious.

```markdown
# Tool Handoff: [Request]

## Capability
-

## Tool or Adapter
-

## Artifacts
- Path or artifact ID:
- Preview:

## Provenance and Licensing
-

## Validation
-

## Cost and Permission Status
-

## Human Decisions Needed
-

## Recommended Next Step
-
```

Do not embed binary output, full provider responses, secrets, or unrelated tool
documentation in the handoff.
