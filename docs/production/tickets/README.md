# Production Tickets

This folder contains structured tickets generated from bugs, playtest observations, validation failures, integration issues, and production findings.

## Owner

- Validation Agent

## Supporting agents

- Production Planner Agent
- Implementation agents
- Documentation Curator Agent

## Ticket command

Use `//ticket` to convert an issue, observation, failed expectation, or playtest note into a ticket.

## Ticket status values

- Proposed
- Accepted
- In Progress
- Needs Validation
- Done
- Deferred
- Rejected
