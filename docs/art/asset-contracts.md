# Asset Contracts

Asset contracts define what an asset must contain before integration. The
contract applies equally to artist-created, generated, procedural, licensed,
and kitbashed assets.

## Common contract

- Asset ID and revision
- Purpose and slice
- Source file
- Runtime export
- Preview image
- Provenance and license
- Target engine and platform
- Technical constraints
- Validation result
- Human approval requirement

## 3D model contract

- Scale and orientation
- Polygon and material budgets
- UVs, normals, and texture sets
- Rig and animation requirements when applicable
- LOD requirements when applicable
- Export format and import settings

## Texture and material contract

- Map types and channel packing
- Resolution and compression target
- Color-space requirements
- Shader/material compatibility
- Tiling, masking, and variant requirements

## UI asset contract

- Source design file
- Screen or state reference
- Exported SVG/PNG or engine-native asset
- Resolution and scaling variants
- Naming and localization considerations
- Accessibility and readability notes
